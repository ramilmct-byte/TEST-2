# Specs

The `spec-driven-research` skill writes here:

- `mission.md`, `tech-stack.md`, `roadmap.md`, `log.md`: one copy each, for the whole project.
- One folder per task, `YYYY-MM-DD-short-name/`, holding `requirements.md`, `plan.md`, `validation.md` and `decisions.md`, plus an `artifacts/` folder for scratch work.

Each file starts from a template in `.agents/skills/spec-driven-research/templates/`. The comments in a template say who decides each section: *you* (the researcher) or the *agent*. The `Status:` line at the top of `requirements.md` moves from `draft` to `approved` (you agreed the spec) to `done` (checked and closed out).

A new chat can pick up the project from these files alone.
